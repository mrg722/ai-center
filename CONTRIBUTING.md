# Contribución

1. Inspecciona el repositorio y la rama actual antes de realizar cambios.
2. Conserva el trabajo existente que sea válido.
3. Usa commits enfocados y claros.
4. Ejecuta lint, typecheck, pruebas y build antes de marcar una tarea como completada.
5. Usa pruebas de navegador de extremo a extremo cuando cambie el comportamiento de la interfaz.
6. No hagas force-push ni elimines ramas sin autorización humana explícita.
