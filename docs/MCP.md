# Estrategia MCP

MCP se utiliza para herramientas y recursos, no como sustituto del orquestador.

## Herramientas previstas

### Playwright
Pruebas de extremo a extremo, navegación, comportamiento responsive y verificación real de la interfaz.

### Firecrawl
Crawling, scraping, extracción estructurada e investigación cuando corresponda.

### Perplexity
Investigación reciente, documentación y segunda fuente cuando sea necesaria.

## Regla

Los adaptadores MCP deben ser opcionales. Si una herramienta no está instalada o configurada, el sistema debe mostrarla como `UNAVAILABLE` y mantener funcional el resto de la plataforma.
